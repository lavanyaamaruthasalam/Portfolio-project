# Customer Segmentation & RFM Analysis (Excel)

This Excel workbook contains the cleaned and formatted source data used for SQL-based customer segmentation and Power BI dashboard development.

## Files Included
- Transactions_1997
- Transactions_1998
- Products
- Customers
- Stores
- Regions

## Data Preparation Performed
- Converted raw datasets into Excel Tables
- Standardized data types and formatting
- Verified consistency across source files
- Prepared data for SQL joins and Analytical Base Table (ABT) creation

## Purpose
The workbook serves as the structured data foundation for building customer metrics, RFM scoring, customer segmentation, and business insights related to retention, churn, and revenue growth.
