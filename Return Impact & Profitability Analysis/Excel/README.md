# Return Impact Analysis (Excel)

This Excel workbook contains the cleaned and formatted source data used for SQL-based return impact analysis and Power BI dashboard development.

## Files Included

- Transactions_1997
- Transactions_1998
- Returns
- Products
- Stores
- Regions
- Calendar

## Data Preparation Performed

- Converted raw datasets into Excel Tables
- Standardized data types and formatting
- Verified consistency across source files
- Validated relationships between transactions, returns, products, stores, regions, and calendar tables
- Prepared data for SQL analysis and Power BI dashboard development

## Purpose

The workbook serves as the structured data foundation for evaluating the impact of product returns on revenue and profitability, measuring return-driven losses, analyzing business performance across products, brands, stores, regions, and time periods, and validating profit margin stability across key business dimensions.
