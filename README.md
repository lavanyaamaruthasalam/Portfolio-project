# Lavanya Maruthasalam – Sales & Data Analytics Portfolio

Welcome to my portfolio repository.

This repository showcases end-to-end business analytics projects built using Excel, SQL, and Power BI. Each project focuses on solving business problems through data preparation, analysis, visualization, and insight generation.

## Tools & Skills Demonstrated

- Excel (Data Cleaning, Formatting, Pivot Tables)
- SQL (Joins, Aggregations, CTEs, Window Functions)
- Power BI (Data Modeling, DAX, Interactive Dashboards)
- Business Analysis
- KPI Development
- Data Storytelling

## Projects

### Retail Sales Analysis
Comprehensive sales performance analysis using 269K+ retail transactions to evaluate revenue, profitability, return impact, and customer behavior.

### Revenue Concentration & Pareto Analysis
Analyzed revenue distribution across brands and products to test whether the business follows the Pareto (80/20) principle. Found that the top 10 brands contributed only 26.47% of total revenue, revealing a diversified long-tail revenue structure.
